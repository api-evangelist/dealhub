## API Reference
- [Get a Specific Quote](https://developers.dealhub.io/reference/getquotebyid.md): Retrieves the details of a single existing quote by its DealHub Quote ID.  This endpoint allows you to fetch specific data points for any quote in DealHub. The level of detail in the response is controlled by the **`feature`** query parameter.  -   **Minimal Response**: If you don't specify any `feature` parameters, the API returns a basic response containing only the `dealhub_quote_id`, its current `status`, and the `quote_upgrade_required` flag. -   **Detailed Response**: To get more information, you must include one or more `feature` query parameters in your request.  If a Draft quote was created using an older one, now-inactive version, the `quote_upgrade_required` flag will be `true`. When this occurs, the API will not return any requested `feature` data for that quote.  > 📘 Date Formats > > All date values in the response are returned in `yyyy-mm-dd hh:mm:ss` format.
- [Get a List of Quotes](https://developers.dealhub.io/reference/getquotes.md): Retrieves a list of quotes, with options for filtering and pagination.   Use the `external_opportunity_id` query parameter to retrieve only the quotes linked to a specific opportunity in your CRM.  The level of detail returned for each quote is controlled by the `feature` query parameter.  Use the `offset` and `limit` parameters to page through large sets of quotes. The default `limit` is 50 quotes per request.  If no quotes match the specified criteria, the API will return a `200 OK` status with an empty `quotes` array.  > 📘 Date Formats > > All date values in the response are returned in `yyyy-mm-dd hh:mm:ss` format.
- [Create an Opportunity](https://developers.dealhub.io/reference/createopportunity.md): Creates a new opportunity within DealHub, typically used for renewal automation.
- [Get Quote Document](https://developers.dealhub.io/reference/getquotedocument.md): Retrieves the output document (e.g., PDF, Word) for a submitted quote. Use this endpoint to archive contracts or integrate quote documents into other systems.  By default, the endpoint returns the document in the format and template that the salesperson originally generated. You can use the optional `document_type` query parameter to request the document in a different format (e.g., `PDF`, `WORD`). However, this is only possible if the requested format has been enabled for the quote's playbook in the CPQ settings.  > 📘 Excel Files > > A quote document can only be retrieved in `EXCEL` format if the quote was explicitly configured to allow an Excel file output.
- [Get DealRoom Signers](https://developers.dealhub.io/reference/getdealroomsigners.md): Retrieves information about who has signed a contract within a DealRoom for a specific opportunity.
- [External Data Query](https://developers.dealhub.io/reference/fulfillexternalquery.md): > ❗️ Important  > > This is not an endpoint provided by DealHub. This page present the endpoint definition you need to make available so DealHub can call it.   DealHub uses this endpoint to send requests that share data from the current quote’s playbook and product list. Your endpoint should process this data and return information that will be populated back into the quote’s playbook.  The specific URL for this endpoint is configured by the administrator in the DealHub UI.  > 📘 Authentication > > When DealHub calls your endpoint, it will include an `Authorization` header based on the configuration set by an administrator in the DealHub UI. Your endpoint must be prepared to handle one of the following methods: > - **Token (Bearer):** DealHub sends a secret bearer token. Your endpoint should validate this token. > - **Basic:** DealHub sends a username and password for Basic Authentication. > - **None:** No `Authorization` header is sent. This is used when the endpoint is unsecured or uses a different security method, such as a token embedded in the URL.
- [Retrieve Real-Time Pricing](https://developers.dealhub.io/reference/getpricing.md): > ❗️ Important > > This is not an endpoint provided by DealHub. This page present the endpoint definition you need to make available so DealHub can call it.  This endpoint enables DealHub to retrieve real-time product prices and attributes from your external system while a quote is being generated.  The specific URL for this endpoint is configured by the administrator in the DealHub UI.  > 📘 Date Formats > > All date and time values are provided in ISO 8601 format and standardized to UTC (Coordinated Universal Time) `yyyy-MM-dd'T'HH:mm:ss.SSS'Z'` (e.g., `2025-09-01T15:39:25Z`).
- [Simulate a Quote](https://developers.dealhub.io/reference/simulatequote.md): Synchronously calculates quote pricing and details based on the provided configuration without creating a persistent quote object in DealHub. Ideal for real-time price calculations.  Use this endpoint to calculate real-time pricing and quote details without creating a permanent record in DealHub. You have to inform the product and configuration data to receive the calculated line items and a financial summary.   To run a simulation, your request must include a `version_id` to specify which pricing and product rules to use. You also need to provide one of the following options:  - `external_opportunity_id`: Use this to base the simulation on an existing opportunity in your CRM. - `geo_code` and `currency`: Use this combination for simulations that do not depend on specific CRM data.  > 📘 Required data >  > You must provide either the `external_opportunity_id` or both the `geo_code` and `currency` parameters. Providing both in the same request will result in an error.  > ❗️ `quote_data` is required > The `quote_data` field is required and must always be present in the request body. If you do not have any line items to include, send it as an empty array: `"quote_data": []` <br/><br/> Omitting the `quote_data` field entirely will result in an error. Note that the auto-generated code example on this page may not include `quote_data` when no line item values are provided, but the field itself must still be present in your request.
- [Generate a Quote](https://developers.dealhub.io/reference/generatequote.md)
- [Submit a Quote](https://developers.dealhub.io/reference/submitquote.md): Asynchronously submits an existing `Draft` quote for approval.
- [Publish a Quote](https://developers.dealhub.io/reference/publishquote.md): Asynchronously publishes an existing `Ready to be sent` quote to a DealRoom.
- [Sign a Quote Externally](https://developers.dealhub.io/reference/signquoteexternally.md): Asynchronously marks an existing quote as `Won`. The quote must be in a `Ready to be sent` or `Published` status.
- [Get DealHub Quote ID](https://developers.dealhub.io/reference/getquoteid.md): Retrieves the `dealhub_quote_id` using the `dealhub_proposal_id` (the ID visible in the UI).
- [Authenticate User](https://developers.dealhub.io/reference/authenticateuser.md): Authenticates a user from an external CRM and returns a short-lived (60 seconds) one-time access token. This is a server-to-server call that uses a long-lived secret token for authorization. If the user does not exist in DealHub, a new user with a `Sales` role is created.
- [Create Quote](https://developers.dealhub.io/reference/createquote.md): Creates a new quote in DealHub and returns a URL to redirect the user to. This is a client-side call that must be authenticated with the one-time access token obtained from the `/user/authenticate` endpoint. This version supports subscription renewals via the `repeatable_groups` parameter.
- [Open Quote](https://developers.dealhub.io/reference/openquote.md): Retrieves a URL for an existing quote in DealHub. The user can then be redirected to this URL to view or edit the quote. This call can optionally update opportunity information for quotes in 'draft' status.
- [View Quotes for an Opportunity](https://developers.dealhub.io/reference/viewquotesforopportunity.md): Retrieves a URL that redirects the user to the **My Proposals** page for a specific opportunity, showing all associated quotes.
- [View My Opportunities](https://developers.dealhub.io/reference/viewmyopportunities.md): Retrieves a URL that redirects the user to their main "My Opportunities" dashboard in DealHub.
- [Start CRM Import](https://developers.dealhub.io/reference/startcrmimport.md): Starts (or joins) an asynchronous import of buyer accounts and their contacts from the tenant's connected CRM into DealHub. Accepts a list of buyer-account CRM ids; duplicates are ignored. Returns a `request_id` immediately, the import runs in the background. If an import is already running for the tenant, its `request_id` is returned instead of starting a new one.
- [Get CRM Import Status](https://developers.dealhub.io/reference/getcrmimportstatus.md): Retrieves the summary of a CRM import: aggregate counts (total, processed, succeeded, failed, skipped) plus a flat list of per-id failures with reasons. This is the service to poll. If `request_id` is omitted, the tenant's most recent import is returned.
- [Get CRM Import Detail](https://developers.dealhub.io/reference/getcrmimportdetail.md): Retrieves the full picture of a CRM import: the same summary as the status service, plus every buyer account and each of its contacts with their own state and failure reason. Use this to see exactly which contacts within an account did or did not migrate.
- [Lookup CRM Import Id](https://developers.dealhub.io/reference/lookupcrmimportid.md): Resolves a single CRM id within an import (whether it is a buyer account, or a contact, or not part of the import) along with its state and failure reason. For a contact match, the buyer-account CRM id it belongs to is also returned.
- [Retry CRM Import](https://developers.dealhub.io/reference/retrycrmimport.md): Re-runs the failed ids of a CRM import (plus any unfinished ids from an interruption) under the same `request_id`. Already-imported accounts are skipped. Asynchronous like Start CRM Import, returns the `request_id` immediately; poll the status service for the outcome.
- [Get User by Login](https://developers.dealhub.io/reference/getuserbylogin.md): Retrieves a single user's details based on their login name. Fields with null values will not be included in the response.
- [Get User by ID](https://developers.dealhub.io/reference/getuserbyid.md): Retrieves a single user's details based on their DealHub user ID. Fields with null values will not be included in the response.
- [Get a List of Users](https://developers.dealhub.io/reference/getusers.md): Retrieves a list of users. If no parameters are provided, it will retrieve all users. Fields with null values will not be included in the response.
- [Update Users (v1)](https://developers.dealhub.io/reference/updateusersv1.md): Updates one or more existing users in DealHub. This operation identifies users by their `login`, which is an immutable field.
- [Create or Update Users (v2)](https://developers.dealhub.io/reference/createorupdateusersv2.md): Creates new users or updates existing ones. The operation uses the `login` field to identify existing users.
- [Authenticate Partner User](https://developers.dealhub.io/reference/authenticatepartneruser.md): Authenticates a partner user from a PRM system and returns a short-lived (60 seconds) one-time access token. This is a server-to-server call that does not require a bearer token in the header, instead, the long-lived authentication key is sent in the request body.
- [Get URL to Create a New Quote](https://developers.dealhub.io/reference/createpartnerquote.md): Retrieves a URL that redirects an authenticated partner user to the quote creation page within DealHub for a specific opportunity. This is a client-side call using the one-time access token.
- [Get URL to Open an Existing Quote](https://developers.dealhub.io/reference/openpartnerquote.md): Retrieves a URL that redirects an authenticated partner user to an existing quote within DealHub. This is a client-side call using the one-time access token.
- [Get URL to View an Opportunity's Quotes](https://developers.dealhub.io/reference/openpartneropportunity.md): Retrieves a URL that redirects an authenticated partner user to the opportunity details page in DealHub, listing all associated quotes. This is a client-side call using the one-time access token.
- [Get Products Parameters](https://developers.dealhub.io/reference/getproductsparameters.md): This service returns a list of parameters required to calculate the price for each SKU.
- [Get Products Pricing](https://developers.dealhub.io/reference/getproductspricing.md): This service returns a price for each SKU in the request.
- [Get Version by ID](https://developers.dealhub.io/reference/getversionbyid.md): Retrieve a specific Version based on its unique DealHub ID.
- [Get Version by Name](https://developers.dealhub.io/reference/getversionbyname.md): Retrieve a specific Version based on its name.
- [Get a List of Versions](https://developers.dealhub.io/reference/getversions.md): Retrieve a list of Versions, with an option to filter by status. If no parameters are provided, it returns all versions.
- [Duplicate a Version](https://developers.dealhub.io/reference/duplicateversion.md): Asynchronously creates a new Version entity based on an existing one. This operation returns a `request_id` for tracking.
- [Activate a Version](https://developers.dealhub.io/reference/activateversion.md): Asynchronously activates a `DRAFT` Version. This operation returns a `request_id` for tracking.
- [Get Playbook Data](https://developers.dealhub.io/reference/exportplaybookdata.md): Retrieves the details of the requested Playbook in a specific version, exporting the Playbook configuration and data in JSON format.
- [Get Generate Quote Template](https://developers.dealhub.io/reference/getgeneratequotetemplate.md): Returns a preformatted JSON template for API quote generation based on the Playbook structure.
- [Get Products of a Version](https://developers.dealhub.io/reference/getversionproducts.md): Retrieves a paginated list of products for a specific version, returning basic product attributes and price details. - `DRAFT` Status: Returns the full product list. - `ACTIVE`/`DEACTIVATED` Status: Can return either all products or only products that were new or modified compared to the previously active version.
- [Get Products by SKU](https://developers.dealhub.io/reference/getproductsbysku.md): Retrieves basic details for a specific list of products from the catalog based on their SKUs.  > 📘 > If some SKUs could not be found in a specific Version the system will return status 200, with error in the `info` structure.
- [Extract Products to Excel](https://developers.dealhub.io/reference/extractproductsexcel.md): Retrieves all product-related information for a specific version in an Excel file format.
- [Get Product Catalog](https://developers.dealhub.io/reference/getproductcatalog.md): Retrieves paginated information about products and bundles in the catalog, including attributes, assignments, and pricing details.
- [Create or Update Product Catalog](https://developers.dealhub.io/reference/uploadproductcatalog.md): This endpoint asynchronously uploads a complete product catalog to a `DRAFT` version. Each product and bundle is created or updated based on the details in the request JSON.  If a SKU already exists in the catalog, it will be completely replaced with the new data from the request, including its pricing, assignments, and other details. If the replacement process fails for any reason, the system will revert to the old product definition.  This operation returns a `request_id` for you to track the progress. Note that requests targeting an `ACTIVE` or `DEACTIVATED` catalog version will fail.
- [Update Product Catalog Items](https://developers.dealhub.io/reference/updateproductcatalog.md): This endpoint asynchronously updates specific data elements for existing SKUs in a `DRAFT` version's product catalog. Unlike the POST endpoint, this endpoint does not create new products — it only modifies data elements for SKUs that already exist in the catalog.  The `mode` query parameter controls the update behavior: `UPDATE` merges the provided data with existing data, while `REPLACE` replaces all entries within each included data category.  This operation returns a `request_id` for tracking. Requests targeting an `ACTIVE` or `DEACTIVATED` version will fail.
- [Delete All Products from Catalog](https://developers.dealhub.io/reference/deleteallproducts.md): Deletes all products and the entire product hierarchy tree from a `DRAFT` version. * This operation can only be triggered for a catalog version with a **`DRAFT`** status. * Requests made for an `ACTIVE` or `DEACTIVATED` catalog version will fail with a `400 Bad Request` HTTP error.
- [Delete Specific Products by SKU](https://developers.dealhub.io/reference/deleteproductsbysku.md): Deletes specific products from the product catalog of a `DRAFT` version.  * This operation can only be triggered for a catalog version with a **`DRAFT`** status. * Requests made for an `ACTIVE` or `DEACTIVATED` catalog version will fail with a `400 Bad Request` HTTP error.  A product cannot be deleted if it is: * A parent to another product in the hierarchy. * Marked as mandatory. * Set as an alternative in the hierarchy tree.
- [Get Asynchronous Request Status](https://developers.dealhub.io/reference/getasyncrequeststatus.md): Polls and retrieves the current status of a specific asynchronous request (e.g., duplicate version, activate version).
- [Get Asynchronous Request Execution Summary](https://developers.dealhub.io/reference/getasyncrequestsummary.md): Retrieves a summary of a completed asynchronous process, including success, error, and warning counts. This is particularly useful for operations like product catalog uploads.
- [Get Product Hierarchy](https://developers.dealhub.io/reference/getproducthierarchy.md): Retrieves the product hierarchy tree for a specific version.
- [Create or Update Product Hierarchy](https://developers.dealhub.io/reference/updateproducthierarchy.md): Asynchronously creates or updates the product hierarchy for a 'DRAFT' version. This operation returns a `request_id` for tracking.
- [Delete from Product Hierarchy](https://developers.dealhub.io/reference/deletefromproducthierarchy.md): Asynchronously deletes specified items (products, bundles, or labels) from the product hierarchy of a 'DRAFT' version.
- [Get the contact for accounts receivable](https://developers.dealhub.io/reference/getaccountreceivablecontact-1.md): Returns the details of the account receivable contact for your tenant
- [Set the contact for accounts receivable](https://developers.dealhub.io/reference/putaccountreceivablecontact-1.md): Sets the details of the account receivable contact for your tenant
- [Get the details of an alias](https://developers.dealhub.io/reference/getsubscriptionchargealias-1.md): Returns the details of the specified alias id including the subscription id and the charge id it is mapped to.
- [Create an alias for a subscription id/charge id pair](https://developers.dealhub.io/reference/addsubscriptionchargealias-1.md): This allows you to specify a string alias for a subscription id and a charge id. This can be useful when, for example, you want to upload usage statistics and would rather specify your own id (or another external id), rather than referring to Subskribe's internal ids.
- [Delete the specified alias](https://developers.dealhub.io/reference/deletesubscriptionchargealias-1.md): Deletes the specified alias mapping
- [Get aliases for a subscription](https://developers.dealhub.io/reference/listaliasesforsubscription-1.md): Returns all aliases for the specified subscription id.
- [Get automated invoice rule details](https://developers.dealhub.io/reference/getautomatedinvoicerule-1.md): Returns the details of the specified automated invoice rule

- [/automatedInvoiceRules/internal/{id}](https://developers.dealhub.io/reference/updateautomatedinvoiceruleusinginternalid.md)

- [Send a test email](https://developers.dealhub.io/reference/sendtestdunningemail-1.md): Sends a test email for dunning to the use associated with this API call. Note A user bound api key is required for this operation.
- [Get dunning settings](https://developers.dealhub.io/reference/getdunningsetting-1.md): Returns the dunning settings for your tenant

- [Get bulk invoice run details](https://developers.dealhub.io/reference/getbulkinvoicerun-1.md): Returns the details of the specified bulk invoice run
- [Get items for bulk invoice run](https://developers.dealhub.io/reference/getbulkinvoicerunitems-1.md): Returns the items associated with the specified bulk invoice run
- [Get invoice balance](https://developers.dealhub.io/reference/getinvoicebalance-1.md): Returns the balance of the specified invoice number

- [Generate subscription invoices](https://developers.dealhub.io/reference/generateinvoice-1.md): Generates the invoices for the given subscription
- [Preview invoices](https://developers.dealhub.io/reference/previewinvoicebyorderperiod-1.md): Returns a preview of invoice for the specified order id OR subscription id
